Diese App nutzt OpenRouter statt Anthropic, weil OpenRouter kostenlose Bild-KI-Modelle anbietet (kein Guthaben nötig). Kostenlosen Key holen: auf openrouter.ai/keys registrieren (kein Zahlungsmittel nötig) und einen Key erzeugen. Der Key bleibt nur lokal in diesem Browser (localStorage) und geht direkt an openrouter.ai — kein Server dazwischen. Ein passendes kostenloses Bild-Modell wird automatisch ermittelt und bei einem Ausfall automatisch ein anderes probiert — das Modellfeld muss nur ausgefüllt werden, wenn ausdrücklich ein bestimmtes Modell erzwungen werden soll.

🎯 Zeichen präzise ausschneiden (SAM, experimentell)

Dein Browser unterstützt WebGPU — damit kann ein echtes Segmentierungsmodell (SAM) ein einzelnes Zeichen auf Klick präzise freistellen, statt es grob zuzuschneiden. Klicke unten auf ein einzelnes, schwer lesbares Zeichen im ersten hochgeladenen Foto; der freigestellte Ausschnitt wird danach zusätzlich geprüft. Ehrlicher Hinweis: Das ist neu und experimentell — das Modell wird beim ersten Klick aus dem Internet nachgeladen (kann je nach Verbindung dauern) und die Erkennung kann fehlschlagen, ohne dass das restliche Ergebnis oben davon betroffen ist.
